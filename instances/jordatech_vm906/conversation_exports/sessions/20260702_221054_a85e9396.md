## What I Learned About Working with Claude Code

### 1. Print mode (`-p`) is the most reliable path
- **Works immediately** with cached credentials — no OAuth dialog
- **Skips all interactive prompts** — trust dialogs, permissions, everything
- **Structured output** with `--output-format json` returns session metadata (session_id, cost, turns)
- **No tmux needed** — direct terminal call, clean and fast
- Set `--max-turns` to prevent runaway costs
- Set `--timeout=120-180` for deep analysis

### 2. tmux interactive mode always triggers OAuth on fresh sessions
- Even though `claude auth status` shows credentials are valid from CLI
- Each NEW tmux session process starts fresh and triggers the OAuth flow
- The cached credentials in `~/.claude/.credentials.json` are NOT automatically picked up by new Claude Code processes
- **This means tmux + interactive mode is unreliable** for programmatic use — it requires manual OAuth paste each time
- If you MUST use interactive mode, the OAuth code needs to be pasted into the tmux session manually

### 3. The `--name` flag doesn't appear on the web portal
- Setting `--name "My Project Name"` sets a display name in the TUI and session metadata
- **It does NOT create a visible project on claude.ai** — the web portal session listing doesn't surface these names
- The session ID is what links sessions, but print mode sessions don't create lasting portal entries

### 4. Session persistence quirks
- Sessions last **5 hours** in interactive mode
- Use `--no-session-persistence` to avoid accumulating sessions on disk
- `--continue` finds the most recent session for the current directory
- Resuming requires the same working directory
