# MIAM-00112 RTX 5060 Ti / Qwen 3.6 35B-A3B / vLLM Deployment Plan

## Objective

Reproduce the successful MIAM-00111 Qwen 3.6 35B-A3B vLLM stack on **MIAM-00112**, while adapting the design for **six NVIDIA RTX 5060 Ti 16 GB Blackwell GPUs** instead of six RTX 3080 20 GB GPUs.

Target model: `QuantTrio/Qwen3.6-35B-A3B-AWQ`  
Served model name: `qwen3.6-35b-a3b`  
Target concurrency: 10 agents  
Power policy during capacity tests: no artificial GPU power cap

## 1. Key differences from MIAM-00111

Known MIAM-00112 architecture:

- GIGABYTE MC62-G40 motherboard
- AMD Threadripper Pro 3955WX, 16 cores / 32 threads
- 128 GB DDR4
- Six RTX 5060 Ti 16 GB GPUs
- GPUs recorded in physical PCIe slots 1, 3, 4, 5, 6, and 7
- PCIe slot 2 has no PCIe device recorded
- No 100 Gb adapter/link recorded
- 10 Gb top network connection recorded
- GPU slots 1/3/4 use PSU MIAM-00165 / PDU 152 outlet 15
- Motherboard + GPU slots 5/6/7 use PSU MIAM-00164 / PDU 152 outlet 16
- Existing architecture notes say the PSU feeding slots 1/3/4 should be powered first on a cold start
- Existing architecture notes also mention RAM slot B ECC errors / a suspected CPU quadrant-3 pin-height or impedance issue

The RTX 5060 Ti is a Blackwell GPU with 16 GB GDDR7 and CUDA capability 12.0. Blackwell requires a CUDA 12.8-or-newer software generation, so the CUDA 13.0-era environment used successfully on MIAM-00111 is an appropriate first replication target.

The lower VRAM is the largest design change. MIAM-00111's final TP1/DP6/EP6 model process occupied roughly 18.9 GB per 20 GB RTX 3080. Therefore, **do not assume TP1/DP6/EP6 will fit on 16 GB cards**.

## 12. Phase 10 - Use a different model-parallel layout than MIAM-00111

Do **not** start with TP1 / DP6.

MIAM-00111 could run:

```text
TP1 / DP6 / EP6
```

because each RTX 3080 had 20 GB.

The preferred first MIAM-00112 attempt is:

```text
TP2 / DP3 / EP6
```

With vLLM expert parallelism enabled:

```text
EP_SIZE = TP_SIZE x DP_SIZE
```

Therefore:

```text
TP2 x DP3 = EP6
```

With TP > 1, attention weights are sharded across each TP group while expert weights are distributed across all six expert-parallel ranks. This is exactly the kind of memory reduction the 16 GB cards need.

Candidate order:

```text
A. TP2 / DP3 / EP6   <- first choice
B. TP3 / DP2 / EP6   <- more sharding if A is too tight
C. TP6 / DP1 / EP6   <- maximum sharding fallback
```

Do not use CPU offload as the first answer. Find the best all-GPU topology first.
